1. 앱에서 진단 기록 삭제 (Delete Diagnosis Records in the App)

  1. 컬러핏의 설정 화면을 엽니다. · Open Settings in 컬러핏.
  2. 진단 기록 삭제를 선택합니다. · Select Delete diagnosis history.
  3. 확인 창에서 삭제를 확정합니다. · Confirm deletion in the dialog.

이 동작은 기기 내 SQLite 데이터베이스의 진단 기록을 삭제합니다. 온보딩 확인 상태나 다른 앱 환경설정, Google·Apple 제공자 정보, 운영체제 또는 SDK 제공자가 관리하는 정보까지 삭제하는 기능은 아닙니다. · This removes diagnosis rows from the on-device SQLite database. It does not remove onboarding state or every app preference, Google/Apple provider information, or data controlled by the operating system or an SDK provider.

2. 기기의 모든 앱 데이터 삭제 (Delete All Local App Data)

Android: 기기 설정 → 앱 → 컬러핏(Personal Color) → 저장공간 → 앱 데이터 삭제. 앱 제거로도 앱 컨테이너의 로컬 데이터가 삭제됩니다.

iOS: 설정 → 일반 → iPhone 저장 공간 → Personal Color → 앱 삭제. “앱 정리하기”는 문서와 데이터를 남길 수 있으므로 전체 삭제가 필요하면 “앱 삭제”를 사용합니다.

English: On Android, use device Settings → Apps → Personal Color → Storage → Clear app data, or uninstall. On iOS, use Settings → General → iPhone Storage → Personal Color → Delete App; “Offload App” may retain documents and data.

3. 로그인과 제공자 계정 (Sign-In and Provider Accounts)

현재 앱에는 운영자 서버 계정은 없습니다. 앱의 로그아웃은 현재 앱 세션을 종료할 뿐이며 Google·Apple 제공자 계정은 삭제되지 않습니다. 제공자 계정 또는 제공자가 보관한 정보는 Google 또는 Apple의 계정·개인정보 관리 화면에서 처리해야 합니다. · The current app has no operator-hosted server account. Signing out ends the current app session only; the Google or Apple provider account is not deleted. Manage the provider account and provider-held information through Google or Apple's account/privacy controls.

4. 사진 임시 파일 (Temporary Photo Files)

사진 선택기가 앱 전용 임시 복사본을 만들 수 있습니다. 앱은 사진을 읽은 뒤 삭제하고 다음 실행 때 남은 복사본도 최선의 범위에서 정리합니다. 앱 중단·읽기 실패·삭제 실패로 남은 임시 복사본은 운영체제의 앱 데이터 삭제 또는 앱 제거로 지울 수 있습니다. 갤러리 원본은 앱 데이터 삭제 대상이 아닙니다. · The photo picker may create an app-specific temporary copy. The app deletes it after reading and makes a best-effort cleanup on a later launch. A copy left after a crash, read failure, or deletion failure can be removed by clearing app data or uninstalling. The original library photo is not part of app-data deletion.
